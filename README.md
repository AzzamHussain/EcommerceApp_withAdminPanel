# E-Commerce With Admin Panel

## Project Overview

### Description:
The E-commerce Application with Admin Panel is a robust mobile app designed to
offer a seamless platform for users to browse and order food items while allowing
restaurant owners to upload deals and manage their menus. The app uses Firebase
Authentication for secure user login, Firestore for real-time database management, and Stripe for safe and efficient payment processing. The application features an
intuitive user interface and includes various Flutter packages for enhanced
functionality and performance.

### Purpose:
The primary objective of developing this application was to gain hands-on experience
with Firebase integration, explore advanced Flutter packages, and implement a
reliable payment gateway using Stripe. This project provided valuable insights into
managing real-time data, secure authentication, and building a dynamic user
experience.


### Features:
- **User Authentication**: Firebase Authentication ensures secure login and signup for users and admins.
- **Admin Panel**: Restaurant owners can upload deals, manage menus, and oversee orders.
- **Order Placement**: Users can browse food items, add them to the cart, and place orders easily.
- **Secure Payments**: Stripe integration enables safe and hassle-free paymentprocessing. 
- **Real-Time Updates**: Firestore manages real-time order tracking and updates.
- **Responsive Design**: A clean and user-friendly interface optimized for various devices.

## Project Details

### Project Background:
This project was developed to expand my knowledge of Flutter, Firebase, and third- party integrations. By combining multiple advanced technologies, the app
demonstrates the ability to manage user and admin functionalities effectively while
ensuring a secure and reliable experience.

### Development Process:
The development process followed the Agile methodology, allowing for iterative improvements and feedback. The stages included:
1. **Planning**: Outlining the application's structure and determining key features.
2. **Design**: Creating user-centric UI designs and layouts. 
3. **Development**:
                   o Setting up Firebase Authentication and Firestore.
                   o Integrating the Stripe payment gateway. 
                   o Building the admin panel for restaurant management.
4. **Testing**: Ensuring smooth functionality, secure data handling, and error-free
performance

### Challenges and Solutions:
- **Firestore Integration**: Handling complex data structures for real-time menu and order management was challenging,but I overcame it through extensive
research and optimization. 
- **Stripe Integration**: Implementing and testing Stripe's secure payment flow required careful attention to detail to ensure compliance and smooth user transactions. 
- **State Management**: Efficiently managing app state using Flutter's provider
package for a responsive and organized codebase

## Functionality

- **Home Screen**: Displays food items and deals uploaded by restaurants.

- **Admin Panel**: Restaurants can upload deals, update menus, and manage orders.

### Backend:
- **Firebase Firestore**: Stores user profiles, orders, menus, and restaurant data.
- **Firebase Authentication**: Ensures secure login for users and admin roles.
